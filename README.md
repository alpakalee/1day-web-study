# 웹 해킹 스터디 (12주)
### (주차별 일정 변동가능)

PortSwigger Web Security Academy를 축으로 12주. 매주 같은 주제의 최근 1day 분석 2건을 붙인다.

## 두 가지 규칙

1. 랩 1차 시도 25분은 AI 없이. 이후 AI 허용.
2. AI가 준 페이로드는 Burp Repeater에서 재구성해 어느 필드가 무엇을 깨는지 설명할 수 있어야 "푼 것"으로 친다.

AI로 CTF는 푸는데 부족한 지점은 대개 요청·응답을 못 읽는 것이다. 1day 분석을 붙이는 이유도 같다. 랩은 취약점이 거기 있다는 걸 알고 시작하지만 패치 diff는 "이 5줄이 왜 취약했나"를 역으로 묻는다.

## 세미나 2시간(예상)

| 시간 | 내용 |
|---|---|
| 0:00–0:30 | 랩 리뷰. 막힌 랩을 화면 공유로 같이 푼다 |
| 0:30–1:00 | 1day 발표 2건 (각 15분) |
| 1:00–1:45 | 발표된 1day 중 하나를 로컬에서 재현 |
| 1:45–2:00 | 다음 주 담당·범위 확정 |
